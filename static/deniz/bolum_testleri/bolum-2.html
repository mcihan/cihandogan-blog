Doğru cevap:Correct answer: B

Sıralı bir geliştirme modelinde erken aşamalarda çalıştırılabilir kod bulunmadığından o dönemde statik test (örneğin gözden geçirmeler) yapılır; dinamik test ancak kod hazır olduğunda mümkün hale gelir. (a) şıkkında otomatik sistem testleri regresyon testinin yerini alamaz; (c) şıkkında yinelemeli modeldeki bileşen regresyon testleri manuel değil otomatik olmalıdır; (d) şıkkında artımlı modeller her artımda hem statik hem dinamik teste ihtiyaç duyar.

In a sequential development model, no executable code exists early on, so static testing (e.g., reviews) is performed then; dynamic testing becomes possible later when code is available. (a) automated system tests cannot replace regression testing; (c) iterative component regression tests should be automated, not manual; (d) incremental models need both static and dynamic testing per increment.

Ayrıntılı çözümDetailed solution

Konu: Yazılım geliştirme yaşam döngüsü (SDLC) modelinin test üzerindeki etkisi. Sıralı modellerde (şelale, V-modeli) her aşama bir öncekinin tamamlanmasıyla başlar; yinelemeli ve artımlı modellerde ise ürün küçük parçalar halinde geliştirilir ve her parça hemen test edilebilir.

Çözüm: Ayırt edici ölçüt basittir: dinamik test çalıştırılabilir kod gerektirir, statik test gerektirmez. Sıralı bir modelde kod ancak gerçekleştirme aşamasında ortaya çıkar; ondan önceki gereksinim ve tasarım aşamalarında yapılabilecek tek test biçimi gözden geçirme ve statik analiz gibi statik tekniklerdir. Dolayısıyla dinamik test doğal olarak yaşam döngüsünün ilerleyen aşamalarına kalır. Doğru cevap (b).

Şıklar: a) Yanlış: Sistem testi otomasyonu regresyon testi ihtiyacını ortadan kaldırmaz; çevikte sık değişiklik regresyon riskini artırır, otomasyon yalnızca bu testleri sürdürülebilir kılar. b) Doğru: Sıralı modelde erken aşamalarda kod olmadığı için dinamik test sonraki aşamalarla sınırlanır. c) Yanlış: Yinelemeli modelde bileşen testleri her yinelemede tekrar koşulur; bu nedenle manuel değil, otomatik yürütülmeleri beklenir. d) Yanlış: Artımlı modelde her artım için hem statik hem dinamik test yapılır; ikisini erken ve geç diye ayırmak modele uymaz.

İpucu: “Kod çalışıyor mu?” sorusu statik ile dinamik testi ayırmanın en hızlı yoludur. Ayrıca “otomasyon regresyonun yerini alır”, “artık gerek kalmaz” gibi mutlak ifadeler içeren şıklar sınavda neredeyse her zaman yanlıştır.

Which of the following is a good testing practice that applies to all software development lifecycles?

Test uzmanları çalışma ürünlerini taslaklar hazır olur olmaz gözden geçirmelidir; bu, sola kaydırma yaklaşımının bir parçası olarak erken testi mümkün kılar. Ayrıntılı çözümDetailed solution

Konu: Tüm yaşam döngüsü modelleri için geçerli iyi test uygulamaları.
